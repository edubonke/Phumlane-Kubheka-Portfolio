# Phumlane Kubheka — Portfolio

A new editorial portfolio designed and built from a blank page in November 2026.

## Design direction

**Technology, made human.** A warm paper, cobalt and citrus identity built for a Johannesburg-based IT support practitioner, web developer and ICT lecturer.

Principles: purposeful hierarchy, restrained visual motion, meaningful interactions, accessible semantics, responsive layout, mobile-first utility, performance and truthful case-study framing.

## Files

- `index.html` — accessible, search-friendly page structure and case studies
- `assets/site.css` — responsive design system
- `assets/site.js` — progressive enhancement and interactive previews, filters, technical demos and theme
- `assets/portrait-full.webp` and `assets/portrait-close.webp` — optimized transparent portraits

## Features

- Actual live website previews in a desktop/mobile modal
- Written problem / role / process / result case studies
- Filterable project collection
- Gentle binary animation confined to the hero
- Light/dark switch with theme-driven portrait flip
- Diagnostic checklist and decimal-to-binary converter
- Reduced-motion support, semantic navigation and keyboard-friendly dialogs

## Notes

Portfolio descriptions distinguish prototypes, concepts and live sites. The EduBonke prototype is **not** described as a verified production backend.

Hosted on GitHub Pages from `main`. No build step required.
