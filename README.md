# Phumlane Kubheka — Portfolio

Personal professional portfolio for IT support, ICT education and web development in Johannesburg, South Africa.

## Run and deploy

This self-contained static website runs directly from `index.html`. Serve the directory locally using `python3 -m http.server 8000` or deploy the root of the `main` branch using GitHub Pages. No API keys, npm dependencies or backend are required. `favicon.svg` is the site icon.

The contact form opens the visitor's email app and does not send or store messages. Public project links refer to repositories; prototype and concept descriptions do not imply production deployment.
